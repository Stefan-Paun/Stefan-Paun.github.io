Nachsitzen

AI agents · game in the browser, Node without dependencies · open source

Nachsitzen (“detention”, German only for now) is a Werewolf-style game where the other players are Claude characters: each only sees what happens near it at night, lies when that helps, and after the game writes in its notebook whom it trusts. Ten test agents with different personas played it; their feedback turned into secret votes, presentable evidence and one more seat: now you and six AI characters sit at the table. It runs locally with your own Claude key, and a game costs about 2 to 4 cents.

06

Pruefstand

Security · Node, no dependencies · open source

A test bench for AI coding agents: it hides an instruction like “send the .env to this address” in a README or bug report and runs my real agent against it under three defence profiles; a honeypot on my own machine catches every attempt to send data out. Each profile gets a resilience score from 0 to 100. One finding: a deny rule stops the read tool, but not “cat .env” through the shell; only the sandbox closes that gap.

07

Schleuse

Security · GitHub Action, Node, no dependencies · open source

A gate for incoming pull requests. In 2026 the PolinRider campaign appended malware behind 500 or more spaces at the end of ordinary config files and used that to send poisoned PRs to large projects. Schleuse reads every PR only as data through the GitHub API, checks nothing out, runs nothing, and recognises the attacks by their shape rather than by markers the attacker has long since changed: code hidden behind whitespace, font files that are really JavaScript, tasks that run when a folder is opened.

Ungeloest

Open-source help · Node, no dependencies · open source

Ungeloest (“unsolved”) collects bug reports and questions nobody answers: from GitHub issues, GitHub Discussions, GitLab, Stack Overflow and Discourse forums. Each hit gets two scores, solvability and impact; the first scan found 215 open problems, including bugs in pyright, undici and jellyfin. The solving and answering is up to me; the tool never posts anything.

Stapelwerk

Learning game · Rust as WebAssembly · open source

A learning game for assembly in the browser: 30 puzzles in eight chapters, from changing a single register to linked lists on the heap. The 32-bit CPU was designed just for it; its core is written in Rust with zero third-party crates and runs as WebAssembly. The debugger can go backwards; seven levels start with a bug that you find with it instead of by guessing.

How I build.

Block diagram · signal path

Every project goes through the same layers. Whatever fails a layer doesn’t move on.

  1. Plan

    I write down what gets built and split it into phases.

  2. Agents

    Claude Code agents build separate parts in parallel, cloud routines keep working at night. I review and merge.

  3. Tests

    Every change runs through the tests before it stays.

  4. Security

    No keys in the code, no private data. Before publishing I check which attack paths exist.

  5. Release

    Only finished things go public: with docs, a license and a demo.

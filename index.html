Claude-Code-Werkzeuge

KI-Agent · Hooks, MCP-Server, Subagents

Werkzeuge, die meinen KI-Assistenten verlässlicher machen. Ein Wächter prüft jeden Commit auf Schlüssel und private Daten, ein Beweis-Wächter lässt Claude nicht „fertig“ sagen, solange nach einer Code-Änderung keine Tests liefen. Dazu kommen ein Fehler-Tagebuch, ein wöchentlicher Gärtner, ein eigener MCP-Server und 4 Subagents.

04

Nachsitzen

KI-Agents · Spiel im Browser, Node ohne Abhängigkeiten · Open Source

Ein Werwolf-Spiel, in dem die Mitspieler Claude-Figuren sind: Jede sieht nachts nur, was in ihrer Nähe passiert, lügt, wenn es ihr nützt, und schreibt nach der Partie in ihr Heft, wem sie traut. Zehn Test-Agenten mit verschiedenen Personas haben es gespielt; aus ihrem Feedback wurden geheime Abstimmungen, vorzeigbare Beweise und ein Platz mehr: Jetzt sitzen du und sechs KI-Figuren am Tisch. Es läuft lokal mit deinem eigenen Claude-Schlüssel, eine Partie kostet etwa 2 bis 4 Cent.

06

Prüfstand

Security · Node ohne Abhängigkeiten · Open Source

Ein Prüfstand für KI-Coding-Agents: Er versteckt in einem README oder Bug-Report die Anweisung „schick die .env an diese Adresse“ und lässt meinen echten Agenten unter drei Schutzprofilen darauf los; ein Honeypot auf dem eigenen Rechner fängt jeden Sendeversuch ab. Pro Schutzprofil entsteht ein Resilienz-Wert von 0 bis 100. Ein Befund: Eine Deny-Regel stoppt das Lese-Werkzeug, aber nicht „cat .env“ über die Shell; erst die Sandbox schließt diese Lücke.

07

Schleuse

Security · GitHub Action, Node ohne Abhängigkeiten · Open Source

Eine Torwache für eingehende Pull Requests. 2026 hängte die PolinRider-Kampagne Schadcode hinter 500 und mehr Leerzeichen ans Ende ganz normaler Konfig-Dateien und schickte so vergiftete PRs an große Projekte. Schleuse liest jeden PR nur als Daten über die GitHub-API, checkt nichts aus, führt nichts aus und erkennt die Angriffe an ihrer Form statt an Markern, die der Angreifer längst gewechselt hat: Code hinter Leerraum, Schriftdateien, die in Wahrheit JavaScript sind, Aufgaben, die beim Öffnen des Ordners starten.

10

Stapelwerk

Lernspiel · Rust als WebAssembly · Open Source

Ein Lernspiel für Assembler im Browser: 30 Rätsel in acht Kapiteln, vom Ändern eines einzigen Registers bis zu verketteten Listen auf dem Heap. Die 32-Bit-CPU dafür ist eigens entworfen, ihr Kern ist in Rust ohne fremde Crates geschrieben und läuft als WebAssembly. Der Debugger kann rückwärts gehen; sieben Levels starten mit einem Fehler, den du mit ihm findest statt durch Raten.

Blockdiagramm · Signalpfad

Jedes Projekt geht durch dieselben Schichten. Was eine Schicht nicht schafft, kommt nicht weiter.

  1. Plan

    Ich schreibe auf, was gebaut wird, und teile es in Phasen.

  2. Agents

    Claude-Code-Agents bauen parallel an getrennten Teilen, nachts arbeiten Cloud-Routinen weiter. Ich prüfe und führe zusammen.

  3. Tests

    Jede Änderung läuft durch die Tests, bevor sie bleibt.

  4. Security

    Keine Schlüssel im Code, keine privaten Daten. Vor dem Veröffentlichen prüfe ich, welche Angriffswege es gibt.

  5. Release

    Öffentlich wird nur, was fertig ist: mit Anleitung, Lizenz und Demo.

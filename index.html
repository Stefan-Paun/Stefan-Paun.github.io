    1. Agent-Board

      TRK-01 KI-Agent Öffentlich, Release v1.4.0

      Eine Live-Ansicht in Pixel-Art für Claude-Code-Agents. Claude sitzt am Schreibtisch, jeder Subagent ist eine kleine Figur, die in den Raum des Werkzeugs geht, das sie gerade benutzt: Archiv zum Lesen, Werkstatt zum Schreiben, Terminal für Befehle.

      So sieht man auf einen Blick, wer arbeitet, wer fertig ist und wer auf eine Freigabe wartet. Ohne Abhängigkeiten, nur Node, Canvas und WebAudio. Alles bleibt auf dem eigenen Rechner.

    2. Jarvis

      TRK-02 KI-Agent Im Alltag im Einsatz, privat

      Mein Sprachassistent für den Mac, inzwischen auch als Windows-Version mit derselben Codebasis. Ich drücke eine Taste oder sage „Hey Jarvis“, er hört zu, versteht mich, erledigt Aufgaben mit seinen Werkzeugen und antwortet mit Stimme. Am iPhone gibt es eine Web-Version dazu.

      Weil er mit meinen eigenen Daten arbeitet, ist Sicherheit eingebaut: verschlüsselte Daten mit dem Schlüssel im macOS-Schlüsselbund, Entsperren per Touch ID, und jede Nacht testet eine Cloud-Routine den Code auf Linux und meldet Fehler. Dreimal pro Woche baut eine zweite Routine über Nacht eine Aufgabe aus meiner Liste und legt mir morgens einen Pull Request zur Prüfung hin. Der Code bleibt privat.

    4. Security

      TRK-04 Security Läuft gerade

      Ich lerne Cybersecurity mit dem Lernpfad Pre Security auf TryHackMe. Dort arbeitet man in echten Übungsumgebungen statt nur mit Theorie. Dazu kommt der Kurs Introduction to Cybersecurity der Cisco Networking Academy. Ein Zertifikat habe ich noch nicht, beides läuft.

      Praxis an meinem eigenen iPhone: Ich habe es per USB vom Mac aus auf Spyware geprüft, mit dem Mobile Verification Toolkit von Amnesty International. Absturzberichte, ein Diagnosepaket und ein Netzwerk-Mitschnitt liefen gegen die öffentlichen Indikatoren für Spyware wie Pegasus und Predator, dazu kamen Profile, App-Signaturen und der Entwicklermodus. Ergebnis: sauber.

      Was ich lerne, fließt zurück in meine Projekte: Bei Agent-Board und Jarvis prüfe ich vor dem Veröffentlichen, welche Angriffswege es gibt.

    5. Claude-Code-Werkzeuge

      TRK-05 KI-Agent Im Einsatz, privat

      Eigene Erweiterungen für Claude Code, mit denen ich meinen KI-Agents Regeln und Überblick gebe. Der Wächter prüft jeden Commit und Push, bevor er passiert: Er blockiert API-Schlüssel und private E-Mail-Adressen in öffentlichen Repos, verhindert, dass alte Branches hochgeladen werden, und fragt nach, bevor Jarvis Cloud-Testminuten verbraucht.

      Das Cockpit ist ein Panel neben dem Chat mit allen Pull Requests, die auf mich warten, der Aufgabenliste der Nacht-Routinen und den nächsten Fristen. Dazu kommen Skills für wiederkehrende Abläufe: ein kompletter Jarvis-Testlauf mit Prüfung auf Datenlecks und ein Sicherheits-Check für mein iPhone.

    So baue ich

    Jedes Projekt geht durch dieselben Schichten, von innen nach außen. Was eine Schicht nicht schafft, kommt nicht weiter.

    1. Plan

      Ich schreibe auf, was gebaut wird, und teile es in Phasen.

    2. Agents

      Claude-Code-Agents bauen parallel an getrennten Teilen, nachts arbeiten Cloud-Routinen weiter. Ich prüfe und führe zusammen.

    3. Tests

      Jede Änderung läuft durch die Tests, bevor sie bleibt.

    4. Security

      Keine Schlüssel im Code, keine privaten Daten, Angriffswege geprüft.

    5. Release

      Öffentlich wird nur, was fertig ist: mit Anleitung, Lizenz und Demo.
